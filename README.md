# LifeMirror Website

This is the static website for the LifeMirror Android app, generated with a premium glassmorphism dark-mode aesthetic. 
It contains:
- `index.html`: A beautiful landing page highlighting the app's features.
- `styles.css`: The CSS styling ensuring a high-quality user experience.
- `script.js`: Interactive scroll animations.
- `privacy.html`: The HTML rendering of the app's privacy policy, ready for Google Play Store compliance.

## Deployment Instructions

Since you have already created the repository at `git@github.com:PieApps/lifemirror.github.io.git`, you can push this setup to GitHub to instantly host it via GitHub Pages.

Run the following commands in this directory (`/var/www/apps/lifemirror/lifemirror.github.io/`) from your terminal:

```bash
git init
git add .
git commit -m "Initial website setup"
git branch -M main
git remote add origin git@github.com:PieApps/lifemirror.github.io.git
git push -u origin main
```

Once pushed, GitHub Pages will automatically host your website at `https://PieApps.github.io/lifemirror.github.io/` (or depending on your GitHub Pages settings, `https://lifemirror.github.io/` if you use a custom domain).

Enjoy your stunning new website!
